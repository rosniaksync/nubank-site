Recriação da landing page do Nubank usando HTML e CSS puro, com foco em layout responsivo.

O projeto parte de um design desktop e se adapta até telas de 360px através de dois breakpoints (900px e 480px). A construção usa Flexbox como base, com max-width em vez de larguras fixas para que os blocos encolham naturalmente antes mesmo das media queries entrarem. A navegação principal dá lugar a um menu dropdown no mobile, e as seções de duas colunas (hero e cartão) empilham verticalmente com o conteúdo centralizado.

Tecnologias: HTML5, CSS3 (Flexbox, media queries, variáveis CSS), Bootstrap (dropdown).
